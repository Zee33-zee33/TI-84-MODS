# 2048 Game Design Document

## Overview
2048 is a sliding tile puzzle game where the goal is to combine numbered tiles to create a tile with the value 2048. This implementation is designed for the TI-84 Plus CE calculator.

## Game Rules

### Board
- 4x4 grid of tiles
- Each tile is either empty (0) or contains a power of 2 (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, ...)

### Starting State
- Game starts with two randomly placed tiles, each showing either 2 (90% probability) or 4 (10% probability)

### Moves
- Player can move all tiles in one of four directions: up, down, left, or right
- When moving, all tiles slide as far as possible in the chosen direction
- If two tiles with the same number collide during a move, they merge into one tile with double the value
- After each successful move (one that changes the board), a new tile (2 or 4) spawns in a random empty cell
- A tile cannot merge twice in the same move

### Scoring
- Score increases by the value of each newly created tile from merging
- Example: merging two 8 tiles creates a 16 tile and adds 16 points to the score
- High score is persisted across game sessions

### Win Condition
- Player wins when a tile with value 2048 is created
- Player can continue playing after winning to achieve higher scores

### Lose Condition
- Game ends when the board is full and no valid moves are available
- A valid move is one that either moves at least one tile or merges tiles

## Controls

### Gameplay Controls
- **Arrow Keys**: Move tiles (Up, Down, Left, Right)
- **Enter**: Undo last move (single-step undo only)
- **2nd**: Pause game
- **Clear**: Quit to menu / Exit game

### Menu Navigation
- **Any Key**: Start game from menu
- **Enter**: New game (from game over screen) or Continue (from win screen)
- **2nd**: Resume game (from pause menu)

### Colors
Tiles use distinct colors based on their value:
- 0 (empty): Light beige (#CDB5B4)
- 2: Light tan (#EEE4DA)
- 4: Light orange (#EDE0C8)
- 8: Orange (#F2B179)
- 16: Darker orange (#F59563)
- 32: Red-orange (#F67C5F)
- 64: Red (#F65E3B)
- 128: Yellow (#EDCF72)
- 256: Yellow-gold (#EDCC61)
- 512: Yellow-gold (#EDC850)
- 1024: Gold (#EDC53F)
- 2048: Gold (#EDC22E)
- Higher: Dark (#3C3A32)

Text color:
- Values 2-4: Dark gray (#776E65)
- Values 8+: White (#FFFFFF)

### Game States

#### Main Menu
- Shows title "2048 - Menu"
- Displays control instructions
- Prompt to press any key to start

#### Playing
- Shows game board with current tiles
- Displays current score and high score
- Responsive to movement controls

#### Paused
- Overlays pause message on game board
- Options to resume or quit

#### Game Over
- Overlays game over message
- Shows final score
- Options to start new game or quit

#### Game Won
- Overlays win message
- Options to continue playing or quit

## Animation and Timing

### Tile Animations
For MVP, animations are not implemented. Future versions may include:
- Tile sliding animation (60-100ms per move)
- Tile merging animation (100ms)
- New tile spawn animation (150ms scale-up effect)

### Input Timing
- Input polling rate: 60 FPS (16.67ms per frame)
- Debounce time: 100ms to prevent accidental double inputs

## Persistence

### Save System
- Game state is saved when pausing or quitting
- High score is always persisted
- Save file: "2048.sav"
- Save includes:
  - Board state (all tile values)
  - Current score
  - High score
  - Game state (playing, won, lost)
  - Move count

### Undo System
- Single-step undo supported
- Stores previous board state and score before each move
- Undo is not available after loading a saved game (reset on load)
- Invalid moves (that don't change board) don't update undo state

### Platform Compatibility
- Core game logic is portable C99
- Engine API provides platform abstraction
- Compilation modes:
  - Host mode: For testing and development on PC
  - TI-84 mode: For deployment to calculator (define TI84_TARGET)

### Build System
- `make build-2048`: Builds the game binary
- `make test-2048`: Runs unit tests
- `make clean`: Removes build artifacts

## Acceptance Criteria

### Functional Requirements
✓ 4x4 game board with proper tile rendering
✓ Arrow key controls for tile movement
✓ Correct merge behavior (only once per move)
✓ New tile spawning after each valid move
✓ Score tracking and display
✓ High score persistence
✓ Single-step undo functionality
✓ Win detection (2048 tile created)
✓ Lose detection (no valid moves)
✓ Pause functionality
✓ Game state saving/loading

### Build Requirements
✓ Compiles with `make build-2048`
✓ Unit tests pass with `make test-2048`
✓ No warnings with -Wall -Wextra
✓ Portable C99 code

### Testing Requirements
✓ Unit tests for move logic in all directions
✓ Unit tests for merge behavior
✓ Unit tests for undo functionality
✓ Unit tests for win/lose detection
✓ Randomized testing for move sequences

### User Experience
✓ Clear visual distinction between tile values
✓ Responsive controls
✓ Intuitive menu navigation
✓ Helpful on-screen instructions
